# Day of the Date Finder

## 📌 Project Overview

The **Day of the Date Finder** is a simple Python program that determines the day of the week for a given date.

The user enters a date in **DD-MM-YYYY** format, and the program uses Python's built-in `datetime` module to calculate and display the corresponding day.

## 🎯 Objective

The objective of this project is to create a beginner-friendly Python application that:

* Accepts a date from the user
* Validates the entered date
* Determines the day of the week
* Displays the result clearly
* Handles invalid date formats

## 🛠️ Technologies Used

* Python 3
* `datetime` module

## ⚙️ How It Works

1. The program asks the user to enter a date.
2. The date is converted into a Python `datetime` object.
3. The program determines the day of the week.
4. The result is displayed to the user.
5. If an invalid date is entered, an error message is displayed.

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Download or clone this project.
3. Open the project folder in a terminal.
4. Run:

```bash
python day_of_date_finder.py
```

5. Enter the date in this format:

```text
DD-MM-YYYY
```

### Example

```text
Enter date (DD-MM-YYYY): 15-08-2026

Date: 15-08-2026
Day: Saturday
```
